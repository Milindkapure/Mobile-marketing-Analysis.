# Mobile Marketing Analysis Dashboard 2025

## 📊 Project Overview

This project is an interactive Mobile Marketing Analysis Dashboard created using Microsoft Power BI.

The dashboard analyzes mobile phone data to understand companies, mobile specifications, RAM, processors, battery capacity, mobile weight, launch years, and prices.

## 🎯 Project Objective

The main objective of this project is to analyze mobile phone data and identify useful business insights related to:

- Mobile companies
- Mobile models
- RAM distribution
- Processor-wise mobile count
- Battery capacity
- Mobile weight
- India mobile prices
- Launch-year trends

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel / CSV

## 📂 Dataset

The dataset contains mobile phone information including:

- Company Name
- Model Name
- RAM
- Processor
- Battery Capacity
- Mobile Weight
- Screen Size
- Launched Price
- Launched Year

## 🧹 Data Cleaning

The raw data was cleaned before creating the dashboard.

The main data-cleaning steps included:

- Checking duplicate records
- Checking blank and missing values
- Correcting data formats
- Standardizing numeric fields
- Cleaning RAM and other unit-based values
- Preparing the data for Power BI analysis

After data cleaning, the dashboard contains 915 mobile records from 18 companies.

## 📌 Dashboard KPIs

- Total Mobiles: 915
- Total Companies: 18
- Average Battery Capacity: 5.03K
- Average Mobile Weight: 228.91
- Latest Launch Year: 2025
